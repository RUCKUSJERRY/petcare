# 수익화 설정 가이드 (토스페이먼츠 · 구글 애드센스)

펫케어의 수익화 기능(프리미엄 정기결제 · 제휴 커머스 · 광고)을 실제로 켜기 위한 키 발급/설정 방법입니다.
모든 키는 코드에 넣지 말고 `.env.local`(로컬) / 배포 플랫폼 환경변수(Vercel)에만 넣습니다.

- `supabase/01_operation/01.2_changes/005_admin_settings.sql` (관리자/운영설정)

## 1. 토스페이먼츠 (프리미엄 정기결제)

결제 방식은 **빌링(자동결제)** 입니다. 카드 1회 등록 → 매월 자동 청구 → 해지 전까지 갱신.

### 1-1. 테스트 키 발급 (계약 불필요, 즉시)

1. https://developers.tosspayments.com 접속 → 로그인/회원가입
2. **개발자센터 → 내 개발정보 → API 키** 이동
3. **테스트** 탭에서 두 키를 복사
   - **클라이언트 키**: `test_ck_...` → `NEXT_PUBLIC_TOSS_CLIENT_KEY`
   - **시크릿 키**: `test_sk_...` → `TOSS_SECRET_KEY` (서버 전용, 절대 노출 금지)
4. `.env.local`에 입력 후 서버 재시작

```bash
NEXT_PUBLIC_TOSS_CLIENT_KEY=test_ck_xxxxxxxxxxxx
TOSS_SECRET_KEY=test_sk_xxxxxxxxxxxx
```

### 1-2. 테스트 결제 해보기

1. 앱 → 프로필 → **펫케어 프리미엄** → "프리미엄 구독 시작하기"
2. 토스 결제창에서 **테스트 카드**로 카드 등록 (실제 청구 없음)
   - 테스트 카드번호는 토스 결제창 안내 또는 개발자센터 문서 참고
3. 성공 시 자동으로 프리미엄 활성화(👑) + 다음 결제일 표시
4. 자동 갱신은 `/api/billing/renew` 크론(매일 1회)이 처리. 수동 확인:
   ```bash
   curl -H "Authorization: Bearer $CRON_SECRET" https://<도메인>/api/billing/renew
   ```

### 1-3. 실서비스 전환 (나중에)

실제 청구를 받으려면:
1. **사업자등록** + 토스페이먼츠 **가맹점 계약**(심사) 완료
2. 개발자센터 **라이브** 탭의 `live_ck_...` / `live_sk_...` 키로 교체
3. 빌링(자동결제)은 별도 신청/약관 동의가 필요할 수 있으니 토스 가이드 확인
4. 정기결제이므로 **이용약관·자동결제 고지·해지 안내**를 화면/약관에 명시 (전자상거래법)

> 가격은 코드 수정 없이 **관리자 페이지(/admin)** 에서 변경합니다. (결제 금액은 서버가 DB값을 신뢰)

## 2. 구글 애드센스 (디스플레이 광고)

### ⚠️ 먼저 알아둘 점 — "광고 보고 시작"과 애드센스의 차이

- 현재 앱의 **전면 광고(산책 시작 전 "광고 → 계속하기")** 는 자체 오버레이로, 지금은 **자체/제휴 상품**을 소재로 띄웁니다.
- **애드센스는 웹 배너/디스플레이 광고** 상품입니다. 즉 페이지에 배너 단위를 심는 방식에 적합합니다.
- 웹에서 **"리워드(보고 보상)" 광고는 애드센스가 제공하지 않습니다.** (리워드/전면 광고는 모바일 앱용 **AdMob** 영역)
- 따라서 현실적인 조합:
  1. **애드센스 배너** → 목록 하단 등 디스플레이 위치에 수익화
  2. **자체 전면 광고** → 그 안에 애드센스 디스플레이 단위를 채우거나, 제휴 상품을 계속 노출
  3. 장기적으로 모바일 앱(스토어 출시) 시 **AdMob 리워드 광고**로 "보고 시작" 정식 수익화

### 2-1. 애드센스 가입 + 사이트 등록

1. https://adsense.google.com 접속 → 구글 계정으로 시작
2. **사이트 URL**(배포 도메인) 입력, 국가/결제 정보 입력
3. 안내된 **애드센스 스크립트**(`ca-pub-XXXXXXXXXXXXXXXX`)를 사이트 `<head>`에 추가
   - Next.js에서는 `src/app/layout.tsx`의 `<head>` 또는 `next/script`로 삽입
4. **사이트 심사**(보통 수일~수주). 콘텐츠/트래픽 요건 충족 필요
   - 충분한 콘텐츠, 개인정보처리방침 페이지, 자체 도메인 권장

### 2-2. 광고 단위 만들고 연결

1. 승인 후 애드센스 → **광고 → 광고 단위 기준** → 디스플레이 광고 생성
2. 발급된 **슬롯 ID**를 환경변수에 입력
   ```bash
   NEXT_PUBLIC_AD_NETWORK_SLOT=1234567890
   ```
3. 코드 연동(추가 작업 필요): `<ins class="adsbygoogle" ...>` 단위를 배너 위치(예: 목록 하단)나
   전면 광고 소재 영역에 렌더링하고 `(adsbygoogle = window.adsbygoogle || []).push({})` 호출.
   - 현재 코드는 슬롯 ID env만 준비돼 있고, 실제 `<ins>` 삽입은 승인 후 별도 작업으로 붙입니다.

### 2-3. 정책 주의

- 클릭 유도/자가 클릭 금지, 광고 과다 배치 금지 (계정 정지 사유)
- 반려동물 콘텐츠는 정책상 무난하나, 의료 정보는 표현 주의

## 3. 환경변수 요약

| 변수 | 용도 | 비고 |
|---|---|---|
| `NEXT_PUBLIC_TOSS_CLIENT_KEY` | 토스 결제창 | 테스트/라이브 키 |
| `TOSS_SECRET_KEY` | 토스 승인·청구 | 서버 전용, 노출 금지 |
| `CRON_SECRET` | 갱신 크론 보호 | 기존 변수 재사용 |
| `NEXT_PUBLIC_PREMIUM_PRICE_KRW` | 가격 폴백 | 평소엔 /admin(app_settings)이 우선 |
| `NEXT_PUBLIC_COUPANG_PARTNER_TAG` | 제휴 링크 태그 | 쿠팡 파트너스 가입 후 |
| `NEXT_PUBLIC_ADS_ENABLED` | 광고 전역 토글 | `false`면 끔. /admin에서도 토글 |
| `NEXT_PUBLIC_AD_NETWORK_SLOT` | 애드센스 슬롯 | 승인 후 |

> 운영 중 가격·광고 ON/OFF는 **코드 수정 없이 `/admin`** 에서 바꿀 수 있습니다.
