## 2. 손익분기 (Break-even)

가정: 정식 운영 고정비 **₩70,000/월**, 프리미엄 **₩3,900/월**, 토스 수수료 3.3% 차감 후 순 **~₩3,771/건**.

- **유료 구독자 약 19명** → 인프라 고정비 손익분기.
- 일반적 freemium 전환율 **1–3%** 가정 시 → **총 활성 사용자 약 600~1,900명** 필요.
- 제휴(쿠팡파트너스 ~3% 커미션)·광고(AdSense)가 더해지면 필요한 구독자 수는 더 내려감.

| 월 순매출 목표 | 필요 구독자(구독만) | 또는 동등 제휴/광고 |
|---|---|---|
| 손익분기(₩70k) | ~19명 | 제휴 매출 ₩70k(= 약 ₩230만 거래액 @3%) |
| 흑자 시작(₩150k) | ~40명 | 혼합 |

## 3. 실제 수익 가능성 (솔직한 평가)

**가능한 것**
- **손익분기(월 ₩7만 커버)는 충분히 현실적.** 충성 사용자 수백 명 + 약간의 제휴 매출이면 도달.
- 제품 완성도는 이미 높음(기록·일정·산책·지도·실종·OCR·커뮤니티·공동관리·푸시·결제·관리자 KPI).

**어려운 것 / 냉정한 한계**
- **"사업으로서 의미 있는 이익"은 어렵다.** 펫 앱은 ARPU가 낮고, 진짜 병목은 *제품이 아니라 유입(마케팅·유통·리텐션)*.
- 구독 ₩3,900·웹 디스플레이 광고(RPM ~₩1–3천/1천뷰) 모두 **규모(트래픽)** 가 전제. 규모 없으면 광고·제휴 수익은 미미.
- 국내 경쟁: 펫프렌즈·어바웃펫(커머스), 펫닥·포동(상담) 등 **자본력 있는 사업자** 존재. 차별화·방어 포인트 필요.

**권장 전략 (우선순위)**
1. **리텐션 우선** — 펫케어의 핵심은 "매일 기록". 수익화보다 *DAU·재방문·기록 지속률*을 먼저 증명. ✅ *관리자 KPI에 리텐션 지표(DAU/WAU/MAU·끈적임·7일 기록 지속률·활성자당 기록 수) 추가됨 (`/api/admin/stats`).*
2. **구독 가치 집중** — "다견/가족 공동관리 무제한 · OCR 무제한 · PDF 리포트" 같이 *돈 낼 이유*가 분명한 묶음.
   ✅ *반영됨 — 이전엔 유료 혜택이 "광고 제거" 하나뿐이었으나, 실제 지불의사가 있는 두 가지를 유료화:*
   - *제출용 PDF 리포트: 무료는 배경 워터마크 포함, 프리미엄은 워터마크 없이 발행(병원·호텔·미용 제출용). (`exportRecords` watermark 옵션 · 일정 화면 `usePlan` 게이팅)*
   - *AI 영수증/이력서 인식: 무료는 월 5회(초과 시 무료 Tesseract 인식으로 폴백), 프리미엄은 무제한. (`/api/medical/ocr` 월 한도 · `app_settings.free_ocr_monthly` 로 조정)*
   - *두 기능 모두 무료 기능을 완전히 막지 않고 "등급화"해, 기존 사용자 이탈은 줄이면서 유료 전환 이유를 만든다. 가족 공유 확대만 아직 준비 중.*
3. **제휴를 자연스럽게** — 기록 기반 추천(예: 사료 소진 시점에 재구매 추천)으로 클릭률↑. ✅ *홈 "맞춤 추천"으로 구현됨 — 임박한 케어 일정(양치·미용·건강검진)·식사 루틴을 신호로 소모품을 이유와 함께 추천 (`getSmartRecommendations`).*
4. **광고는 트래픽 확보 후** — 초기엔 UX 해치지 않게 최소화.

## 4. 투자자 관점 요약
- **강점**: 기능 완성도 + *수익화 3종(구독·제휴·광고)·투자자 KPI 대시보드(전환율/ARPU/ARPPU/churn)* 내장 → 데모 설득력.
- **질문받을 것**: ① **리텐션 증거**(DAU·재방문) — *관리자 대시보드에 DAU/WAU/MAU·끈적임·기록 지속률 지표 내장(수치 추적 시작)*, ② **차별화/방어**, ③ **획득 채널(CAC)**.
- **한 줄**: 제품은 시드 데모 수준 충분 — 분기점은 **"리텐션 증거 + 획득 채널"**.

## 5. 사용자 관점 요약
- **좋은 점**: 원탭 기록·오늘 타임라인·1마리 자동선택·사진 폴백 등 체감 좋은 UX.
- **아쉬운 점(개선 진행 중)**: 신규 등록 폼 조작감 → *필드별 인라인 검증·오류 위치로 자동 스크롤 반영*.
  비용의 기록 종속 개념 → *빈 상태에서 기록 추가 폼으로 원탭 딥링크*. 다견 선택 스크롤 → *가로 스크롤 페이드 힌트*.

## 7. 신뢰성 · 결제 정합성 (유료 서비스 필수)

유료(정기결제) 서비스는 **"돈은 빠졌는데 권한 미반영"** 같은 정합성 사고가 곧 신뢰·환불·CS 비용으로 직결된다.

- **결제 후 DB 반영 실패 가시화(반영됨)**: 첫 달 청구(`/api/billing/issue`)·자동 갱신(`/api/billing/renew`) 모두
  청구 성공 후 `payments`/`profiles` 갱신 오류를 **조용히 넘기지 않고 결제키와 함께 치명 로그**로 남긴다 → 운영자 수동 복구 가능.
- **권한 기준 일원화**: 프리미엄 혜택은 `profiles.plan`·`premium_until` 단일 기준(`usePlan`)으로 판정.
- **남은 과제(권장)**: 다단계 결제 갱신을 Supabase RPC/트랜잭션으로 원자화, 결제-권한 불일치 자동 재조정(reconcile) 배치.

> 규모가 커지기 전이라도 **결제 정합성 로그는 선반영**해 두는 것이 실제 매출 신뢰의 최저 비용 보험이다.
