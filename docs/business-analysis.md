- **토스페이먼츠 결제수수료**: 건당 **약 3.3%** (고정 월비 없음). + **사업자등록** 필요(정기결제 실서비스 시).

## 2. 손익분기 (Break-even)

가정: 정식 운영 고정비 **₩70,000/월**, 프리미엄 **₩3,900/월**, 토스 수수료 3.3% 차감 후 순 **~₩3,771/건**.

- **유료 구독자 약 19명** → 인프라 고정비 손익분기.
- 일반적 freemium 전환율 **1–3%** 가정 시 → **총 활성 사용자 약 600~1,900명** 필요.
- 제휴(쿠팡파트너스 ~3% 커미션)·광고(AdSense)가 더해지면 필요한 구독자 수는 더 내려감.

| 월 순매출 목표 | 필요 구독자(구독만) | 또는 동등 제휴/광고 |
|---|---|---|
| 손익분기(₩70k) | ~19명 | 제휴 매출 ₩70k(= 약 ₩230만 거래액 @3%) |
| 흑자 시작(₩150k) | ~40명 | 혼합 |

## 3. 실제 수익 가능성 (솔직한 평가)

**가능한 것**
- **손익분기(월 ₩7만 커버)는 충분히 현실적.** 충성 사용자 수백 명 + 약간의 제휴 매출이면 도달.
- 제품 완성도는 이미 높음(기록·일정·산책·지도·실종·OCR·커뮤니티·공동관리·푸시·결제·관리자 KPI).

**어려운 것 / 냉정한 한계**
- **"사업으로서 의미 있는 이익"은 어렵다.** 펫 앱은 ARPU가 낮고, 진짜 병목은 *제품이 아니라 유입(마케팅·유통·리텐션)*.
- 구독 ₩3,900·웹 디스플레이 광고(RPM ~₩1–3천/1천뷰) 모두 **규모(트래픽)** 가 전제. 규모 없으면 광고·제휴 수익은 미미.
- 국내 경쟁: 펫프렌즈·어바웃펫(커머스), 펫닥·포동(상담) 등 **자본력 있는 사업자** 존재. 차별화·방어 포인트 필요.

**권장 전략 (우선순위)**
1. **리텐션 우선** — 펫케어의 핵심은 "매일 기록". 수익화보다 *DAU·재방문·기록 지속률*을 먼저 증명. (관리자 KPI에 리텐션 지표 추가 권장)
2. **구독 가치 집중** — "다견/가족 공동관리 무제한 · OCR 무제한 · PDF 리포트" 같이 *돈 낼 이유*가 분명한 묶음.
3. **제휴를 자연스럽게** — 기록 기반 추천(예: 사료 소진 시점에 재구매 추천)으로 클릭률↑.
4. **광고는 트래픽 확보 후** — 초기엔 UX 해치지 않게 최소화.

## 4. 투자자 관점 요약
- **강점**: 기능 완성도 + *수익화 3종(구독·제휴·광고)·투자자 KPI 대시보드(전환율/ARPU/ARPPU/churn)* 내장 → 데모 설득력.
- **질문받을 것**: ① **리텐션 증거**(DAU·재방문) 부재, ② **차별화/방어**, ③ **획득 채널(CAC)**.
- **한 줄**: 제품은 시드 데모 수준 충분 — 분기점은 **"리텐션 증거 + 획득 채널"**.

## 5. 사용자 관점 요약
- **좋은 점**: 원탭 기록·오늘 타임라인·1마리 자동선택·사진 폴백 등 체감 좋은 UX.
- **아쉬운 점**: 핵심 기능(산책/실종/건강) 발견성, 신규 등록 폼 모바일 조작감.
